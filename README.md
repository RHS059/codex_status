# Codex Status

Live, public progress dashboard for the active Codex agent team.

The page is static and reads `status.json` once per second. Progress updates only change that data file; the dashboard contains no credentials, prompts, local paths, or private logs.

The node canvas is unbounded. Drag the grid or use the mouse wheel to pan; hold Ctrl or Command while scrolling to zoom around the pointer. The toolbar and `+`, `-`, and `0` keys also control the view. Live data changes animate the card outline, crossfade text, and charge or drain the segmented progress meter.

Published URL: <https://rhs059.github.io/codex_status/>
